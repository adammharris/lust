# L0508: dependency crate has no lust form yet

<!-- lust-args: --manifest-path {work}/l0508/Cargo.toml --bin l0508wrong -->

The path or import uses a dependency crate that lust cannot compile
yet: it is not a workspace or path crate lust builds from source, and
it has no lust adapter (for crates such as `hashbrown`) or shim (for
crates such as `rustix`) yet. The message names the crate. Path and
workspace dependencies in edition 2024 work; build other crates with
Cargo, or remove the dependency from the lust dev build. A registry
package that is plain Rust inside lust's subset can compile from its
downloaded source: name it in the project's `source-deps` config
(docs/dev-features.md), as `name` or `name@version`.

An adapter crate (docs/ARCH.md section 3.6) stands in for one exact
upstream version with a known feature set. A lockfile that pins
another version, or a build that enables a feature the adapter does
not implement, also gets this code; the message names the version or
the feature.
